# Support matrix

Version: `0.1.0` (experimental)

This matrix separates a working primitive, an automated reference profile, and a certified product
promise. All 19 library packages are workspace-local and unpublished to npm. Nothing below is a
stable compatibility or conformance claim.

## Declared experimental profiles

| Profile                            | Automated scope                                                                                                                                                                                                                                                                                                                                                                                                                                 | Explicit boundary                                                                                                                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `compact-react-chromium-desktop`   | React 19.2.8 Panefold Code suite in one Playwright Chromium reference environment: semantic commands, solved geometry, center and four-edge panel placement, pointer/keyboard splitters, configurable logical tab rails, IndexedDB reload restoration, live same-origin popup transfer/redock/loss recovery, reduced motion, forced colors, all 17 heavy fixture classes, raw splitter-frame capture, and one 390×844 emulated-touch subprofile | Not a browser/OS matrix, real third-party heavy-content test, physical phone, permissioned PiP/multi-screen profile, manual AT assessment, physical performance certification, or crash/security certification |
| `framework-adapter-contract-jsdom` | Vue 3.5, Svelte 5, Angular 21, and Web Components immutable snapshot, dispatch, selection, observer isolation, lifecycle disposal, and SSR-safe import contracts in JSDOM                                                                                                                                                                                                                                                                       | Not browser rendering/hydration/accessibility/performance certification and not third-party adoption evidence                                                                                                  |

The latest checked-in browser result is
[`chromium-reference-2026-08-14.json`](../conformance/results/chromium-reference-2026-08-14.json).
It records 28/28 passing browser tasks and the exact limitations. Results do not silently widen
profile scope.
The same result directory retains the framework contract, protocol/motion, independent semantic
oracle, interaction-frame, and 50,000-attempt projection reports; each records its own environment,
thresholds, and limitations.

## Unsupported product or certification claims

| Claim                                    | Status      | Reason                                                                                                                              |
| ---------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Unrestricted browser-popout profile      | Unsupported | One controlled same-origin Chromium popup fixture is not a cross-browser/cross-origin/crash product matrix                          |
| Document Picture-in-Picture profile      | Unsupported | The injected path exists, but no permission-capable browser result is published                                                     |
| Multi-screen profile                     | Unsupported | No Window Management permission, placement, DPR/zoom, or monitor-removal result exists                                              |
| Durable distributed collaboration        | Unsupported | The authenticated single-writer port does not provide transport, key service, durable host/recovery, or application conflict policy |
| Arbitrary untrusted-plugin certification | Unsupported | The iframe host is a bounded primitive; no independent sandbox/provenance/deployment assessment exists                              |
| Production heavy-content certification   | Unsupported | The 17-kind fixture is controlled evidence, not a third-party editor/map/grid/media matrix with heap traces                         |
| Physical mobile/touch certification      | Unsupported | Touch emulation does not cover physical hardware, virtual keyboards, pinch/zoom, TalkBack, or mobile VoiceOver                      |
| Stable conformance certification         | Unsupported | Applicable traces and all ten hard release gates are not verified                                                                   |

Unsupported product actions must be omitted or visibly disabled with a reason. Technical primitives
must not be relabeled as best-effort product support. The machine-readable authority is
[`conformance/manifest.json`](../conformance/manifest.json),
[`conformance/capabilities.json`](../conformance/capabilities.json), and
[`conformance/traces.json`](../conformance/traces.json).
