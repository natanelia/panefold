# Support

Panefold `0.1.0` is experimental, source-only software. The workspace packages are not published to
npm, and the project does not offer a compatibility promise, response-time commitment, or
production support SLA.

- Start with the [documentation](https://natanelia.github.io/panefold/docs/), then check the detailed
  [support matrix](docs/SUPPORT.md) and [command support](docs/COMMANDS.md).
- Ask reproducible usage questions or report defects with the
  [GitHub issue forms](https://github.com/natanelia/panefold/issues/new/choose).
- Discuss proposed changes through a feature request before investing in a large implementation.
- Report suspected vulnerabilities privately by following [SECURITY.md](SECURITY.md). Never put
  secrets, private workspace data, or exploit details in a public issue.

When requesting help, include the commit SHA, Node and pnpm versions, browser/OS or framework where
relevant, a minimal reproduction, and the exact expected and observed behavior. Sanitized workspace
snapshots are useful; application data is not.
